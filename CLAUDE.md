# DeleteCookies — Project Instructions

A Chrome extension that deletes cookies.

## Key Files

| File | Purpose |
|---|---|
| `manifest.json` | Chrome extension manifest (entry point) |
| `background.js` | Background service worker — cookie-deletion logic |
| `icon_16.png`, `icon_32.png`, `icon_48.png`, `icon_128.png` | Extension icons |
| `MEMORY.md` | Persistent project memory (read at session start) |
